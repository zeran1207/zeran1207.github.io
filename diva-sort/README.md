# バトスピ ディーバ キャラソート

スマホのブラウザで遊べるキャラソートです。

## ファイル

- `index.html` … 画面
- `script.js` … キャラソート本体
- `style.css` … デザイン
- `images/` … キャラクター画像を入れる場所
- `gas/Code.gs` … Google Apps Scriptの集計サーバー

## 1. GitHubに公開する

1. GitHubで新しいリポジトリを作成。
2. このフォルダの中身をアップロード。
3. Settings → Pages → GitHub Actions（またはDeploy from a branch）で公開。
4. 発行されたURLをスマホで開く。

画像を用意したら `images/` のSVGファイルを同名の画像に置き換えてください。
PNG/JPGを使う場合は `script.js` の画像ファイル名も変更してください。

## 2. 集計機能を使う

1. Googleスプレッドシートを新規作成。
2. 拡張機能 → Apps Script。
3. `gas/Code.gs` の内容を貼り付けて保存。
4. デプロイ → 新しいデプロイ → ウェブアプリ。
5. 「実行するユーザー」は自分。
6. 「アクセスできるユーザー」は全員。
7. `/exec` で終わるURLをコピー。
8. `script.js` の

   API_URL: ""

   を

   API_URL: "ここに/execのURL"

   に変更してGitHubへ再アップロード。

これで「この結果を集計に送る」と「みんなの集計を見る」が使えるようになります。

## 注意

このサンプルのキャラクター一覧は8人です。
実際に公開する際は、使いたいディーバの一覧・画像ファイル名を `script.js` と `gas/Code.gs` の両方で同じにしてください。

キャラクター画像は、利用規約・権利関係を確認したうえで使用してください。
